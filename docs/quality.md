## Как считаем

- Эталонный набор — 14 документов, которые мы написали сами (`backend/demo/reference`). В `labels.yaml` для каждого документа перечислены нарушения, которые находит эксперт.
- Наблюдение — одна проверка на одном документе. Нарушение — положительный класс: **точность** — доля верных среди найденных нарушений, **полнота** — доля найденных среди размеченных.
- Ответ «требует проверки юристом» не считается найденным нарушением: для полноты это пропуск. Число таких ответов показано отдельно.
- Проверки, которые не выполнились (например, модель не подключена), в точность и полноту не входят и показаны в столбце «Не выполнено».
- «—» — считать не из чего: проверка не нашла ни одного нарушения (точность) или в наборе нет размеченных для неё нарушений (полнота).
